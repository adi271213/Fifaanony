# MnemBound artifact requirements

## Core reproduction (Mode A)

Core paper reproduction — running `./verify.sh`, recomputing per-cell rates
from saved responses, running BCESV, computing audit kappa, and rendering
the headline tables — requires only the Python 3.10+ standard library.
No external packages need to be installed.

## Figure regeneration (optional)

Regenerating `paper/fig_robustness.pdf` from saved data requires:

    matplotlib >= 3.5

Install with:

    python3 -m pip install --break-system-packages matplotlib

Then:

    cd analysis
    python3 make_figure_robustness.py --data ../data --out ../paper/fig_robustness.pdf

The figure PDF/PNG output already in `paper/` was generated by this exact
script and the saved data in `data/`; matplotlib is needed only if you
want to regenerate the figure from scratch.

## Retrieval-realism sanity check (optional, artifact-only)

Running `analysis/retrieval_realism_sanity.py` — released as an artifact-
only sanity check, not used to compute any headline number — requires:

    rank-bm25
    sentence-transformers
    numpy

This script is documented in `analysis/RETRIEVAL_REALISM_NOTE.md`.

## Full regeneration of LLM responses (Mode B, optional)

To regenerate the 14,400 LLM responses in `data/<condition>/responses.jsonl`
from scratch, you need GPU access and `vllm`. The two model checkpoints
used in the paper are:

    Qwen/Qwen3-30B-A3B-Instruct-2507-FP8
    unsloth/Mistral-Small-3.2-24B-Instruct-2506-FP8

This is not required for any claim in the paper to be checkable; the
released `responses.jsonl` files are the canonical evidence.
