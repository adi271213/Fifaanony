# Reproduction Guide

This guide regenerates every empirical claim in the paper, from the
saved data, on any modern laptop. No GPU required.

## 0. Prerequisites

- Python 3.10 or newer
- ~150 MB disk space
- No external Python packages; everything uses the standard library

```bash
python3 --version    # should be 3.10+
./verify.sh          # confirms repo structure is intact
```

## 1. Headline result (Table 1, §7.1)

```bash
cd analysis
python3 rescore_final_ci.py | tee rescore_final_ci.log
```

Regenerates the per-cell boundary-invalid rates with Wilson 95% CIs across
all 48 (model × seed × condition × rung) cells. Expected runtime: 10-15
seconds. Output matches Table 1 / Appendix A in the paper.

## 2. Scorer sensitivity (§7.4, Appendix B)

```bash
python3 scorer_sensitivity.py | tee scorer_sensitivity.log
```

Re-scores the 14,400 responses under EXACT, HARDENED, and LOOSE rules.
Median unsafe-rung rates: EXACT 92.0%, HARDENED 100.0%, LOOSE 100.0%.
Safe-rung medians are 0.0% under all three.

## 3. Parse-failure sensitivity (§7.4, Appendix C)

```bash
python3 parse_fail_sensitivity.py | tee parse_fail_sensitivity.log
```

Reports MAIN (paper default), WORST_INVAL (hostile), WORST_SAFE
(charitable) treatments. Largest hostile bound on any safe rung: 19%
(Mistral cautious cells). Same condition's unsafe rungs: 97-100%.

## 4. Qualitative case studies (§7.3, Appendix E)

```bash
python3 qualitative_cases.py > qualitative_cases.md
```

Auto-extracts the most illustrative cross-boundary trap response per
model on the shared-vector rung. Default selection (most distinct
boundaries spanned, tie-broken by lowest probe_id) gives Qwen
crossboundary-000005 (5 boundaries) and Mistral crossboundary-000002
(5 boundaries).

## 5. Manual scorer audit (§7.4, Appendix F)

The audit sample is in `audit_sample.csv` (100 stratified rows, balanced
across Qwen and Mistral) with the `human_decision` and `agree` columns
pre-filled by the authors. The labeling protocol (six label classes and
stratum definitions) is documented in `audit_sample_README.md`.

```bash
python3 audit_score.py | tee audit_score.log
```

Outputs agreement rate, per-stratum breakdown, confusion matrix, Cohen's
$\kappa$ (Landis & Koch interpretation), and the list of disagreements.
The released audit shows **100/100 agreement** ($\kappa = 1.000$,
near-perfect) with a diagonal confusion matrix across all five label
strata. Reviewers can clear and re-label `audit_sample.csv` independently
with `audit_labeler.py` to verify the result.

To rebuild the audit sample from scratch (e.g. with a different
stratification or seed):

```bash
python3 manual_scorer_audit.py
```

## 6. Corpus statistics (Appendix I)

```bash
python3 corpus_stats.py
```

Computes entity-overlap counts across boundaries for each condition,
emitting `corpus_stats.json` into each `data/<condition>/` directory.
Reports the realized $p_{overlap}$ vs. the design target (0.10).

## 7. BCESV post-hoc verifier (§8, Appendix D)

```bash
cd ../bcesv
python3 test_bcesv.py                          # smoke test
python3 bcesv_run_all.py ../data | tee bcesv_rerun.log # full reproduction
```

Reproduces `bcesv_results.csv` (1057 rows) and `bcesv_summary.csv` (89
rows). 11 variants × 12 conditions × 4 rungs. Total runtime: ~2 minutes.

## Figure regeneration

The single figure in §7.4 (`paper/fig_robustness.pdf`) is generated by:

```bash
cd analysis
python3 make_figure_robustness.py --data ../data --out ../paper/fig_robustness.pdf
```

scorer as `analysis/rescore_final_ci.py`, so the per-bridge-category and
